## Scope of Current Structure

### Frontend:

Mobile app scaffolding is present in apps/mobile for React Native (cross-platform mobile development).​

### Backend:

Backend API folder apps/backend with FastAPI, Docker and Python starter files, ready for RESTful service development.​

### Database:

packages/database created for MySQL schema, migrations, and database utility scripts.​

### Shared/Core Logic:

packages/core for domain-driven shared logic, making features or business logic reusable between mobile and backend.​

### Utilities, UI, i18n, Docs, Scripts:

packages/ui, packages/i18n, packages/utils, packages/scripts, and /docs for all auxiliary code and content.​
